Lantern Harbor is a spot-the-difference game with three original code-drawn scenes — Harbor Dusk, Forest Camp, and Market Morning — each hiding 8 differences between two near-identical pictures. Click a difference in either panel to ring it on both, watch how many remain, beat the timer, and ask for a hint (H) or restart (R). Keyboard play works too: move the crosshair with the arrow keys and press Enter. No assets, no network — every picture is drawn in code and the game runs fully offline from static files. Open `game/index.html` in a desktop browser to play.

## Run it

```sh
node main.ts
```
